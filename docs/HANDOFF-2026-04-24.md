## Path A — TTS-free preview (recommended for "just let me see it")

`hyperframes preview` is the studio (equivalent to Remotion Studio). It runs against an `index.html` composition, not against audio. To get a composition without TTS, stub `timings.json` from the storyboard's `target_duration_sec`, then compose, then preview.

**Run this whole block top-to-bottom:**

```bash
# 1. Generate a stub timings.json from storyboard.json (no real audio).
RUN=$(cat .last-run)
node -e "
const fs=require('fs');
const path=require('path');
const sb=JSON.parse(fs.readFileSync(path.join('$RUN','storyboard.json'),'utf8'));
let t=0;
const scenes=sb.scenes.map(s=>{
  const e={id:s.id,kind:s.kind,start_sec:t,duration_sec:s.target_duration_sec,word_count:0};
  if(s.story_num) e.story_num=s.story_num;
  t+=s.target_duration_sec;
  return e;
});
const out={
  audio_file:'narration.wav',
  total_duration_sec:t,
  scenes,
  words:[{text:'stub',start_sec:0,end_sec:0.1}]
};
fs.writeFileSync(path.join('$RUN','timings.json'),JSON.stringify(out,null,2));
console.log('OK stub timings.json — '+scenes.length+' scenes, '+t+'s total');
"

# 2. Build run dir (copies things into a hyperframes project layout).
node pipeline/build-run-dir.mjs "$RUN"

# 3. Compose index.html.
#    In Claude Code: type  /yt-compose
#    Or invoke the yt-compose skill manually pointing at $RUN.
#    The skill needs: storyboard.json + timings.json + screenshots-manifest.json — all present.

# 4. Lint.
npx hyperframes lint "$RUN"

# 5. Open the studio (no MP4 render).
npx hyperframes preview "$RUN"
# → opens http://localhost:3002 — live-edit the composition in the browser
```

**Caveats:**
- Scene timing will be wrong (target durations, not real audio length) — the visual layout/design will be accurate, the pacing will not.
- 2 of 3 screenshots are missing (TechCrunch URLs timed out). The composition will use placeholder source chips for those — you'll see the slot, not the screenshot. To fix: re-run `node pipeline/capture-screenshots.mjs "$RUN"` (the 2 timeouts may resolve on retry).
- The `words` array is stubbed — any caption/highlight feature in the composition will be empty.
